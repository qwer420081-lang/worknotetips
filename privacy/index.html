ABOUT WORKNOTE

Privacy notice

This notice explains the information the site currently processes.

Search and example use

The site itself has no sign-up, comment, payment, form submission, or file upload features. It does not ask for your name or email address.

Search runs in your browser and does not send search terms to a server or AI service. Search terms may appear in the URL hash (#q=…), so take care when sharing an address or screenshot. Clearing the search removes them.

The copy button writes code to the clipboard only when you click it. It does not read the clipboard. Examples run on the computer where you downloaded them and do not upload input files.

Advertising and analytics

This site uses Google Analytics 4 (measurement ID G-NZFH8DJJJ5) to count visits and see which pages are read. The script sets cookies in your browser and sends Google the page address, referrer, approximate location from your IP address (the IP address is anonymised), and browser and device type. It does not collect your name, email address, or the text you type into the search box.

Google processes this data as described in its own privacy policy. Google Analytics keeps event data for 14 months. To opt out, use your browser's tracking protection, block cookies for this site, or install the Google Analytics opt-out add-on (https://tools.google.com/dlpage/gaoptout).

Advertising scripts are not used. If advertising is added later, this notice will be updated first.

Hosting and external materials

The hosting provider may process logs such as IP addresses, access times, and request details to deliver and secure the site. The hosting provider handles login for private deployments.

When you open an external link, that site's policies apply. This site uses fonts on your device rather than loading web fonts from external services.

Scope of this notice

This notice is current as of 2026-09-21. The actual hosting agreement, log retention period, operator, and contact channel must be confirmed before public operation. Information that has not been provided has not been invented.

Analytics on this browser

We measure tutorial opens and successful copy actions, without sending the copied text or search terms in these events. You can turn analytics off on this browser. This preference is stored locally; it also lets site editors exclude their own checks. Clearing browser storage resets it.
