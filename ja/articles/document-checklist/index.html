対象読者表や数値を報告書、会議資料、業務案内などの文書へ移す担当者

準備するもの
  • 元データと作成中の文書について、読み取り専用のコピーを用意します。
  • 表の対象範囲、期間、集計基準を説明する資料を探します。基準が不明な場合は、未確認として記録します。
  • 計算機または計算できるツールと、ダウンロードしたチェックリストを用意します。

01この記事で完成させるもの

完成させるのは数値を詰め込んだ報告書ではなく、読者が最初に読んだ時点で同じ意味に理解できる表と説明文です。まず表の対象範囲を確定し、計算を確認し、最後に単位を付けて文章を書きます。この順序にすることで、表は8月データを基準にしているのに文章は7月を基準にしている、といった異なる基準の混在を減らせます。

確認してください

以下の依頼件数と測定値は、説明用に作成した合成データです。実在する組織の業務実績や測定結果ではありません。

02まず表の対象範囲を1行で定義する

数値そのものが正しくても、数えている対象が異なれば比較できません。この例では「各月に受け付け、その月末までに完了した依頼」を数えます。前月に受け付けて今月完了した依頼は含めません。この定義を表の下に残しておくと、完了件数と、その分母である受付件数の関係が明確になります。

  • 対象: 人数、依頼件数、処理回数のどれを数えているのかを区別します。
  • 期間: 月の区切りが受付日基準なのか完了日基準なのかを明記します。
  • 除外: キャンセル、重複、繰越分をどのように扱うか記録します。
  • 出典: ファイル名だけでなく、バージョンまたは抽出日、該当する表と行も記録します。

03表を文章にする手順

  1. 元データを保持し、作業用コピーを作成します。並べ替えやフィルターを変更する前に、総行数と現在のフィルター条件を記録します。
  2. 表のタイトルと各列名に、対象、期間、単位を入れます。異なる単位の数値は先に換算してから、同じ列に入れます。
  3. 合計と小計に何が含まれているか確認します。明細行を足して作った合計に、小計をもう一度加えないでください。
  4. 分子と分母を並べて比率を再計算します。分母が 0 または欠損している場合は 0 % と書かず、計算できない理由を示します。
  5. 計算中は十分な桁数を保持し、表示するときだけ決めた桁数に丸めます。
  6. 文章中の数値を表と照合し、最後に出典と未解決事項を付けます。数値を修正した場合は、タイトル、要約、グラフ説明も探して修正します。

05数値と単位は一緒に変更する

元データ換算文書内
Length 1.25 m1.25 × 1000Length 1250 mm
Mass 2450 g2450 ÷ 1000Mass 2.45 kg
Temperature 23.5 °C単位換算なしTemperature 23.5 °C

列タイトルを mm に変更したのに値を 1.25 のままにすると、元の長さとは 1,000 倍異なる意味になります。表全体の単位を変更する場合は、値、列タイトル、脚注、本文をまとめて確認します。表で単位が1種類だけなら、各セルに記号を繰り返す代わりに「Length (mm)」のようにタイトルへ記載できます。

BIPM の SI Brochure では、数値と単位記号の間に空白を置くこと、単位記号を一貫して使用すること、同じ表の列内で数値形式を統一することなどの原則が説明されています。23.5 °C と書き、mm と m、MPa と Pa を区別してください。業務文書の金額や件数については組織の表記規則に従い、通貨と、千・百万などの倍率がある場合はそれも明記します。

06完成しているか確認する方法

  1. source-data.json の2行について、受付件数と完了件数を再確認します。表の 120, 96, 150, 123 と1つずつ比較します。
  2. 2つの完了率、その差、受付件数の増加率を独立して計算します。結果が 80.0 %, 82.0 %, 2.0 pp, 25.0 % であることを確認します。
  3. 合成の単位換算例 1.25 m = 1250 mm と 2450 g = 2.45 kg を確認します。
  4. 文書内で「completion rate」「received」「mm」「kg」を検索し、同じ値が異なる単位や期間で繰り返されていないか確認します。
  5. checklist.txt に完了印を残し、未解決の基準は担当者または元データで確認します。チェックマークが付いていても、元データ自体が正確であることを保証するものではありません。

症状原因修正方法

08対象範囲とダウンロードファイルの使い方

この確認手順は、数値を文書へ移す過程で発生する誤りを見つけるためのものです。元データの欠落、業務上の定義の妥当性、測定機器の校正までは検証しません。値が矛盾する場合は、都合のよい方を選ばず、両方の出典と差を記録してください。法定様式や契約で特定の単位・丸め規則が指定されている場合は、それらを別途確認してください。
