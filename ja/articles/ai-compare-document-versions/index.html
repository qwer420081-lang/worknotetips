AIの業務活用

AIで文書の2つのバージョンを比較する：変更・追加・削除・同一を区別する

同じイベント案内のV1とV2をAIに提示し、5つの比較項目を変更・追加・削除・同一に分けて確認する実習です。削除された文を勝手に解釈せず、文書に実際に記載されている差分だけを記録する方法を学びます。

対象読者文書の修正前後の違いを素早く整理したいものの、AIに何をどのように比較させればよいかまだ慣れていない初心者

準備するもの
  • 2つのバージョンの文書をテキストとしてコピーできれば十分です。
  • 実際の個人情報や社内資料ではなく、以下の架空資料だけを使用します。
  • プログラム実行やコーディングは必要ありません。

01比較する2つのバージョンを項目ID付きで準備する

文書比較で最初に行うことは、V1とV2の文を混ぜずに区別することです。この実習では架空のイベント案内を使用し、それぞれの文にA1〜A4とB1〜B4という行IDを付けます。IDを付けると、AIがどの文を根拠に判断したのかを人が再確認しやすくなります。以下の資料には個人情報は含まれておらず、すべての人物・イベント・条件は架空です。

入力資料
[イベント案内 V1]
A1 イベント日時: 11-14 14時
A2 定員: 20名
A3 申込締切: 11-10
A4 持ち物: ノート

[イベント案内 V2]
B1 イベント日時: 11-14 15時
B2 定員: 24名
B3 申込締切: 11-10
B4 オンライン参加: 提供しない

2つのバージョンには合計8つの行がありますが、比較する意味上の単位は正確に5つです。イベント日時、定員、申込締切、持ち物、オンライン参加です。V1の持ち物の文がV2にないという事実と、V2にオンライン参加の文が新しく追加されたという事実は異なる変化なので、別々の項目として扱います。

比較項目V1の根拠V2の根拠比較する内容
イベント日時A1B111-14は同じで、時刻が14時から15時に変わったか確認
定員A2B220名と24名を比較
申込締切A3B311-10のままか確認
持ち物A4該当行なしV2で項目がなくなったか確認
オンライン参加該当行なしB4V2で新しい項目が追加されたか確認

02比較基準をプロンプトに明記する

単に2つの文書を比較してほしいと依頼すると、表現の違いと意味の違いが混ざることがあります。この実習では比較項目を正確に5つに限定し、状態も変更・追加・削除・同一のいずれかだけにします。特に、V2で持ち物の文が消えたからといって、持ち物が不要になったと解釈してはいけません。文書にない理由は分からないためです。

プロンプト
以下のV1とV2を比較してください。

比較項目は正確に5つだけ使用してください。
1. イベント日時
2. 定員
3. 申込締切
4. 持ち物
5. オンライン参加

各項目の状態を変更、追加、削除、同一のいずれかで表示してください。V1の根拠IDとV2の根拠IDを併記し、違いを1文で説明してください。

重要なルール:
- 文書にない理由を推測しないでください。
- V2で持ち物項目がなくなったからといって、持ち物が不要だと断定しないでください。
- 日付や数字を変更したり補足したりしないでください。
- 根拠のない説明を追加しないでください。

[資料]
V1: A1 イベント日時 11-14 14時 / A2 定員 20名 / A3 申込締切 11-10 / A4 持ち物 ノート
V2: B1 イベント日時 11-14 15時 / B2 定員 24名 / B3 申込締切 11-10 / B4 オンライン参加 提供しない

プロンプトの要点は、何を比較するかだけでなく、何をしてはいけないかも記載することです。特に、削除と意味変更は異なります。文の削除は文書状態についての観察であり、必要かどうかの判断には別の情報が必要です。

03結果例で5つの項目を1つずつ照合する

以下の結果は、実際のAI製品の性能を試した結果ではありません。このチュートリアルで入力と出力の対応関係を示すために、AIの補助を用いて構成・確認した編集例です。読者は表の状態や数字を原文と直接照合する必要があります。

結果例
1. イベント日時 — 変更
根拠: A1, B1
11-14は同一だが、開始時刻が14時から15時に変更された。

2. 定員 — 変更
根拠: A2, B2
定員が20名から24名に変更された。

3. 申込締切 — 同一
根拠: A3, B3
申込締切は両方のバージョンで11-10である。

4. 持ち物 — 削除
根拠: A4, V2に該当行なし
V1の持ち物「ノート」の項目はV2では確認できない。削除理由や持ち物の必要性は資料だけでは判断できない。

5. オンライン参加 — 追加
根拠: V1に該当行なし, B4
V2にオンライン参加を提供しないという項目が新しく追加された。
項目判定確認する原文人が確認するポイント
イベント日時変更A1 ↔ B114時が15時に変わったか
定員変更A2 ↔ B220名が24名に変わったか
申込締切同一A3 ↔ B3両方とも11-10か
持ち物削除A4 ↔ V2なしノートがV2にないという事実だけを記載しているか
オンライン参加追加V1なし ↔ B4「提供しない」という否定表現が維持されているか

04削除された項目を勝手に解釈する誤りを見つける

文書比較で注意すべき誤りは、原文の変化とその理由を混同することです。V2に持ち物の文がないことは確認できますが、主催者がノートを不要としたと結論づける根拠はありません。また、オンライン参加の項目は単なる追加ではなく、「提供しない」という否定条件まで保持する必要があります。

誤った結果例
持ち物 — 変更
V2ではノートが不要になったため、準備しなくてもよいです。

オンライン参加 — 追加
V2からオンライン参加が可能です。

最初の文は削除理由を推測しており、2つ目の文はB4の意味を正反対に変えています。正しくは、持ち物項目がV2で確認できないとだけ記録し、オンライン参加については「提供しない」という原文の否定をそのまま維持します。

誤った表現問題修正原則
ノートが不要になった削除理由を勝手に推測しているV2で持ち物項目が確認できないとだけ記録
オンライン参加が可能「提供しない」という否定を逆にしているオンライン参加を提供しないという原文をそのまま維持

05問題があれば全体を書き直さず、誤り部分だけを再依頼する

結果の一部だけが誤っている場合は、最初からすべて比較し直すよりも、修正範囲を指定した方が確認しやすくなります。再依頼では、誤った項目、原文の根拠、変えてはいけない事実を一緒に書きます。そうすることで、修正前後を人が直接比較できます。

プロンプト
前の比較結果のうち、持ち物とオンライン参加の項目だけ修正してください。

修正ルール:
- A4には持ち物「ノート」がありますが、V2には持ち物の行がありません。したがって状態は削除とし、ノートが不要になったという推論は削除してください。
- B4はオンライン参加「提供しない」です。オンライン参加可能に変えないでください。
- その他のイベント日時、定員、申込締切の結果は変更しないでください。
- 最終結果は正確に5項目を維持してください。

この再依頼では、すでに正しい3項目を変更しないよう明示しています。修正作業でも、原文の日付、時刻、定員などの値が意図せず変わることがあるため、最後に5項目すべてを再度照合する必要があります。

06原文を見ながら最終確認する

AIの比較結果は最終判定表ではなく、人が確認するための下書きとして使います。特に変更文書では、一文字の違いよりも、日付、数字、否定語、追加・削除の有無が重要な場合があります。以下のチェックリストを原文の横に置き、1つずつ確認します。

確認リスト
[ ] 比較項目はイベント日時、定員、申込締切、持ち物、オンライン参加の正確に5つか？
[ ] A1とB1の14時 → 15時の変更は正しいか？
[ ] A2とB2の20名 → 24名の変更は正しいか？
[ ] A3とB3の申込締切11-10は同一と表示されているか？
[ ] A4がV2にないという事実を削除として記録しているか？
[ ] 持ち物の削除を「不要」と解釈していないか？
[ ] B4のオンライン参加「提供しない」という否定が維持されているか？
[ ] 原文にない変更理由や方針を新たに作っていないか？

実際の業務文書を比較するときも同じ原則を適用できます。まず比較単位を決め、各文に識別子を付け、AIが示した状態を原文と再照合します。機密性のある実資料ではなく、練習段階では架空テキストを使う方が安全です。

自分で確認する項目

架空のイベント案内V1・V2を対象に、入力行ID、5つの比較項目、数字・日付・否定表現の対応関係を人が読んで確認した編集例

  • 比較項目数が正確に5つか確認
  • A1〜A4とB1〜B4の値が結果で変わっていないか確認
  • 持ち物の削除を「不要」と推測していないか確認
  • オンライン参加「提供しない」という否定表現が保持されているか確認
検証範囲の限界

結果例はAIの補助を用いて構成・確認した教育用の編集例であり、特定のAI製品で実際に実行した結果や、正確度・性能を検証した結果ではありません。

AIでお知らせからFAQを作る：原文にない答えは「要確認」のまま残す

短いお知らせ文から6つのFAQを作り、根拠がある質問にはsource IDを付け、料金・返金・キャンセル待ちのように原文にない内容は勝手に答えを作らない方法を練習します。

AIで自由記述の意見をテーマ別に整理する：複数ラベルと分類保留を扱う

6つの短い自由記述意見を決められたテーマに分類し、1つの意見に2つのテーマが含まれる場合は複数ラベルを許可する実習です。ラベル合計が回答者数を上回ることがある理由と、根拠のない満足度や感情の強さを推測しない方法も確認します。

AIで難しい利用案内をやさしい言葉に直す：条件・例外・否定・期限を保つ

架空の資料貸出案内4文を分かりやすい表現に直しながら、登録会員という条件、7日の期限、予約資料は延長不可、非予約資料は1回の延長申請が可能だが承認は確定ではないという重要条件を失わない方法を練習します。

AIで調査質問と検索計画を作る

漠然とした調査目標を事実質問・経験質問・判断質問に分け、何をどこで確認すべきか検索計画を作る実習です。AIに検索結果を作らせるのではなく、確認すべき資料と未確認項目を先に整理します。

AIで利用者調査のインタビュー質問を作る

架空の申込フォーム利用体験を調べるための15分インタビュー質問をAIと設計する実習です。誘導質問を最近の実際の行動に関する中立的な質問へ修正し、まだ実施していないインタビューの予想回答を実際の証拠として扱わない方法を扱います。

制約条件を決めてAIでアイデアを発想する

参加人数、時間、印刷物、購入可否、使用機材などの制約条件を先に固定し、AIに互いに異なる4つの代案を発想させる実習です。どのアイデアが最も良いか決めるのではなく、各案が条件を守っているか確認し、条件が変わったときに再依頼する方法を扱います。

AIで発表練習用の質問と回答を準備する

すでに整理された架空の発表資料を基に、想定聴衆質問6つと根拠、短い回答、分からない場合の確認計画を作る実習です。発表構成の作成やAI音声評価ではなく、限られた根拠を誇張せず質問に答える練習に焦点を当てます。
