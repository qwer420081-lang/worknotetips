AIで難しい利用案内をやさしい言葉に直す：条件・例外・否定・期限を保つ

対象読者堅い利用案内を一般の読者に分かりやすくしたいものの、重要な条件や例外が消えてしまわないか心配な初心者

準備するもの
  • 原文を文ごとに分けてコピーできれば十分です。
  • 以下のS1〜S4は法規ではなく、完全に架空の運用案内です。
  • 実際の会員情報や個人情報を入力する必要はありません。

01やさしい言葉に直す前に、必ず残す条件を確認する

やさしい言葉への編集の目的は、内容を削ることではなく、同じルールをより理解しやすく表現することです。そのため、文を直す前に、会員条件、期間、禁止事項、申請可能回数、承認の有無など、なくなると意味が変わる要素を先に確認します。以下は実在する図書館や組織の規則ではなく、このチュートリアル用の架空運用案内です。

入力資料
S1 貸出は登録会員のみ可能。
S2 返却は貸出日を含めて7日以内に行う。
S3 予約資料は延長できない。
S4 非予約資料は返却期限前に1回、延長を申請できるが、申請しただけで延長承認が確定するわけではない。
source ID必ず保持する要素変えてはいけない意味
S1登録会員のみ誰でも貸出可能に変えてはいけない
S2貸出日を含む、7日以内貸出翌日から7日など、計算基準を変えてはいけない
S3予約資料、延長不可条件付きで延長可能に変えてはいけない
S4非予約資料、期限前、1回、延長申請可能、承認未確定申請可能を自動承認に変えてはいけない

特にS4は、1文の中に複数の条件が入っています。やさしい文として分けることはできますが、非予約資料という対象、期限前という期限、1回という回数、申請と承認の違いをすべて残す必要があります。

02分かりやすい表現と意味保持を同時に依頼する

単に「分かりやすく書いて」とだけ依頼すると、条件が省略されることがあります。そのため、何を必ず保持するかをプロンプトに直接書きます。この実習では短い文と日常的な言葉を使いながら、新しい特典や例外を作らないよう制限します。

プロンプト
以下の架空の利用案内S1〜S4を、初心者にも分かりやすいやさしい言葉に直してください。

ルール:
- 各source IDの意味をそのまま保持してください。
- 条件、例外、否定表現、数字、期限を削除したり弱めたりしないでください。
- S1の「登録会員のみ」を維持してください。
- S2の「貸出日を含めて7日以内」を維持してください。
- S3の「予約資料は延長不可」を維持してください。
- S4の「非予約資料」「返却期限前」「1回」「延長申請可能」「承認確定ではない」をすべて維持してください。
- 「申請可能」を「承認済み」または「自動延長」に変えないでください。
- 原文にない手数料、罰則、追加延長、例外を作らないでください。

結果はsource IDごとのやさしい文と、原文から保持した重要条件を一緒に示してください。

やさしい表現は、文を短くしたり1文を2文に分けたりして作れます。しかし、原文より利用者の権利や義務が広がったり狭まったりすると、それは単なる編集ではなくルール変更になります。

03原文とやさしい言葉の文を1行ずつ対応させる

以下の結果は、実際のサービスの文章変換性能を測定したものではありません。意味保持の方法を示すために、AIの補助を用いて構成・確認した編集例です。読みやすいかどうかより先に、原文の条件がすべて残っているかを確認する必要があります。

結果例
S1 やさしい言葉: 資料を借りられるのは登録会員だけです。
保持した条件: 登録会員のみ貸出可能

S2 やさしい言葉: 借りた日を含めて7日以内に返却してください。
保持した条件: 貸出日を含む、7日以内

S3 やさしい言葉: 予約されている資料は貸出期間を延長できません。
保持した条件: 予約資料、延長不可

S4 やさしい言葉: 予約されていない資料は、返却期限前に1回だけ延長を申請できます。ただし、申請しただけで延長が承認されたことにはなりません。
保持した条件: 非予約資料、期限前、1回、申請可能、承認未確定
ID原文の要点やさしい言葉の要点保持状況
S1登録会員のみ可能登録会員だけ借りられる保持
S2貸出日を含め7日以内借りた日を含め7日以内保持
S3予約資料は延長不可予約資料は延長できない保持
S4非予約資料は期限前に1回延長申請可能、承認確定ではない予約されていない資料は期限前に1回申請可能、申請だけでは承認されない保持

04分かりやすくなっていてもルールが変わった文を見つける

最も注意すべき誤りは、「申請できる」という文を「延長できる」または「承認される」という文に変えることです。表現上は小さな違いに見えても、利用者に伝わる条件は大きく変わります。期限計算で「貸出日を含む」という表現が消えることも同じ種類の問題です。

誤った結果例
S2 やさしい言葉: 資料は借りた翌日から7日間利用できます。

S4 やさしい言葉: 予約されていない資料は返却日までに1回、自動で延長できます。
誤った部分原文と変わった点修正方法
借りた翌日から7日S2の「貸出日を含む」という条件を変更している借りた日を含めて7日以内に戻す
自動で延長S4の「申請可能」を承認または自動処理に変えている1回延長を申請できるが承認確定ではない状態に戻す

やさしい言葉への編集では、情報を削ることよりも論理関係を保つことが重要です。文が少し長くなっても、申請と承認の違いを説明する2つ目の文を残す方が適切です。

05原文自体が曖昧なら、推測せず確認質問を作る

やさしい言葉に直す過程で、原文に定義されていない部分が見つかることもあります。たとえば、延長申請がどの基準で承認されるのかはS4に書かれていません。この場合、AIに規則を作らせるのではなく、担当者に確認する質問一覧を作るよう依頼できます。

プロンプト
S1〜S4の意味は変えず、利用者が追加で知りたい可能性があるものの、原文だけでは答えられない確認質問を作成してください。

条件:
- 原文にない答えを推測しないでください。
- 質問だけを書いてください。
- 特にS4の延長申請の承認基準や処理方法が原文に定義されているかを区別してください。
- 新しい規則、罰則、手数料、例外を作らないでください。
結果例
確認が必要な質問例:
1. 非予約資料の延長申請はどのような基準で承認されますか？
2. 延長申請の承認可否は利用者にどのような方法で案内されますか？
3. 延長が承認された場合、新しい返却期限はどのように決まりますか？

上記の質問への回答はS1〜S4にはないため、別途確認が必要です。

確認質問を作ったからといって、その答えまで推測してよいわけではありません。原文にない部分を未確定のまま残す方が、誤った規則を作るより適切です。

06読みやすさより先に意味が同じか最終確認する

最終確認では、原文とやさしい文を並べ、条件、数字、期限、否定表現を確認します。自然な文章かどうかを判断するのはその後です。特に「のみ」「以内」「不可」「申請」「承認」のような語は意味が変わりやすいため、個別に確認するとよいでしょう。

確認リスト
[ ] S1で「登録会員のみ」という条件が残っているか？
[ ] S2で「貸出日を含む」という計算基準が残っているか？
[ ] S2の7日が別の数字に変わっていないか？
[ ] S3で「予約資料は延長できない」という否定が維持されているか？
[ ] S4が非予約資料だけに適用されるという条件が残っているか？
[ ] S4の「返却期限前」という期限が残っているか？
[ ] S4の延長申請回数が1回のままか？
[ ] 「申請可能」を自動承認や確定承認に変えていないか？
[ ] 原文にない手数料、罰則、例外、承認基準を新たに作っていないか？

実在する組織の利用規約や法的文書を扱う場合は、担当者の確認や別の基準が必要になることがあります。この文章はそのような判断を代替するものではなく、法規ではない架空の運用案内を使って、やさしい言葉への編集で原文の意味を保つ基本手順だけを練習します。

自分で確認する項目

法規ではない架空の運用案内S1〜S4を対象に、条件・期限・否定・申請と承認の違いがやさしい言葉の版でも保持されているかを人が照合した編集例

  • 登録会員のみという条件が維持されているか確認
  • 貸出日を含めて7日以内がそのままか確認
  • 予約資料は延長不可が維持されているか確認
  • 非予約資料の期限前1回の延長申請可能と承認未確定がすべて保持されているか確認
  • 原文にない規則や例外を追加していないか確認
検証範囲の限界

結果例はAIの補助を用いて構成・確認した教育用の編集例であり、実在する組織の規則、法的解釈、特定AI製品の変換精度や最新機能を検証した結果ではありません。

AIで調査質問と検索計画を作る

漠然とした調査目標を事実質問・経験質問・判断質問に分け、何をどこで確認すべきか検索計画を作る実習です。AIに検索結果を作らせるのではなく、確認すべき資料と未確認項目を先に整理します。

AIで利用者調査のインタビュー質問を作る

架空の申込フォーム利用体験を調べるための15分インタビュー質問をAIと設計する実習です。誘導質問を最近の実際の行動に関する中立的な質問へ修正し、まだ実施していないインタビューの予想回答を実際の証拠として扱わない方法を扱います。

制約条件を決めてAIでアイデアを発想する

参加人数、時間、印刷物、購入可否、使用機材などの制約条件を先に固定し、AIに互いに異なる4つの代案を発想させる実習です。どのアイデアが最も良いか決めるのではなく、各案が条件を守っているか確認し、条件が変わったときに再依頼する方法を扱います。

AIで発表練習用の質問と回答を準備する

すでに整理された架空の発表資料を基に、想定聴衆質問6つと根拠、短い回答、分からない場合の確認計画を作る実習です。発表構成の作成やAI音声評価ではなく、限られた根拠を誇張せず質問に答える練習に焦点を当てます。
