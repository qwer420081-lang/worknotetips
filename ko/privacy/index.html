검색과 예제 사용

사이트 자체에는 회원가입, 댓글, 결제, 양식 제출 또는 파일 업로드 기능이 없습니다. 이름이나 이메일을 입력받지 않습니다.

검색은 브라우저 안에서 이루어지며 서버나 AI 서비스에 검색어를 보내지 않습니다. 검색어는 주소의 해시(#q=…)에 표시될 수 있으므로 주소나 화면을 공유할 때 주의하세요. 초기화하면 지워집니다.

복사 버튼은 누를 때만 코드를 클립보드에 쓰며 클립보드를 읽지 않습니다. 예제는 내려받은 컴퓨터에서 실행되고 입력 파일을 업로드하지 않습니다.

광고와 통계

이 사이트는 방문 수와 어떤 글이 읽히는지 확인하려고 Google 애널리틱스 4(측정 ID G-NZFH8DJJJ5)를 사용합니다. 이 스크립트는 브라우저에 쿠키를 저장하고, 페이지 주소, 유입 경로, IP 주소로 추정한 대략적인 지역(IP 주소는 익명 처리), 브라우저와 기기 종류를 Google에 보냅니다. 이름, 이메일 주소, 검색창에 입력한 내용은 수집하지 않습니다.

수집된 자료는 Google의 개인정보처리방침에 따라 처리되며, 이벤트 데이터는 14개월 동안 보관됩니다. 수집을 원하지 않으면 브라우저의 추적 방지 기능을 켜거나 이 사이트의 쿠키를 차단하거나 Google 애널리틱스 차단 브라우저 부가 기능(https://tools.google.com/dlpage/gaoptout)을 설치하면 됩니다.

광고 스크립트는 사용하지 않습니다. 나중에 광고를 넣게 되면 이 안내를 먼저 고치겠습니다.

호스팅과 외부 자료

호스팅 제공자는 사이트 전달과 보안을 위해 IP 주소, 접속 시각, 요청 정보 등의 로그를 처리할 수 있습니다. 비공개 배포본의 로그인은 호스팅 제공자가 처리합니다.

외부 링크를 열면 해당 사이트의 정책이 적용됩니다. 웹폰트를 외부에서 불러오지 않고 기기의 글꼴을 사용합니다.

현재 안내의 범위

안내 기준일은 2026-09-21입니다. 실제 호스팅 계약·로그 보관 기간·운영자 및 문의 창구는 공개 운영 전 확인해야 합니다. 미제공 정보는 임의로 만들지 않았습니다.

이 브라우저의 방문 통계

글 열기와 복사 성공을 측정하며, 이 이벤트에 복사한 내용이나 검색어는 보내지 않습니다. 이 브라우저에서 통계를 끌 수 있습니다. 선택은 브라우저에 저장되며 운영자의 검수 방문을 제외할 때도 사용할 수 있습니다. 브라우저 저장 공간을 지우면 선택이 초기화됩니다.
