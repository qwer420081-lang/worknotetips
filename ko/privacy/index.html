현재 사이트에서 실제로 처리하는 정보를 설명합니다.

검색과 예제 사용

사이트 자체에는 회원가입, 댓글, 결제, 양식 제출 또는 파일 업로드 기능이 없습니다. 이름이나 이메일을 입력받지 않습니다.

검색은 브라우저 안에서 이루어지며 서버나 AI 서비스에 검색어를 보내지 않습니다. 검색어는 주소의 해시(#q=…)에 표시될 수 있으므로 주소나 화면을 공유할 때 주의하세요. 초기화하면 지워집니다.

복사 버튼은 누를 때만 코드를 클립보드에 쓰며 클립보드를 읽지 않습니다. 예제는 내려받은 컴퓨터에서 실행되고 입력 파일을 업로드하지 않습니다.

광고와 통계

현재 광고와 방문 분석 스크립트는 비활성화되어 있습니다. 사이트 자체 코드가 광고·분석용 쿠키나 추적 도구를 생성하지 않습니다.

광고 또는 분석 도구를 연결하기 전에는 실제 데이터 처리, 동의 방식, 보관 기간과 운영자 연락 방법에 맞춰 이 안내를 갱신해야 합니다.

호스팅과 외부 자료

호스팅 제공자는 사이트 전달과 보안을 위해 IP 주소, 접속 시각, 요청 정보 등의 로그를 처리할 수 있습니다. 비공개 배포본의 로그인은 호스팅 제공자가 처리합니다.

외부 링크를 열면 해당 사이트의 정책이 적용됩니다. 웹폰트를 외부에서 불러오지 않고 기기의 글꼴을 사용합니다.

현재 안내의 범위

안내 기준일은 2026-09-19입니다. 실제 호스팅 계약·로그 보관 기간·운영자 및 문의 창구는 공개 운영 전 확인해야 합니다. 미제공 정보는 임의로 만들지 않았습니다.
