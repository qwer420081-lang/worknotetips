준비사항

  • 계산기 또는 계산 가능한 도구와 내려받은 점검표를 준비합니다.

01이 글에서 완성할 것

완성할 결과는 숫자를 많이 넣은 보고서가 아니라, 독자가 한 번에 같은 의미로 읽을 수 있는 표와 설명 문장입니다. 먼저 표의 범위를 고정하고, 계산을 확인한 뒤, 마지막에 단위를 포함한 문장을 씁니다. 이 순서를 지키면 표는 8월 자료인데 본문은 7월 기준인 것처럼 서로 다른 기준이 섞이는 일을 줄일 수 있습니다.

확인해 주세요

아래 요청 건수와 측정값은 설명을 위해 직접 만든 합성 자료입니다. 실제 조직의 업무 성과나 측정 결과가 아닙니다.

02표의 범위를 먼저 한 줄로 정의하기

숫자 자체가 맞아도 무엇을 센 것인지 다르면 비교할 수 없습니다. 이 예제에서는 “각 월에 접수된 요청 중 같은 월 말까지 완료한 건”을 셉니다. 이전 달에 접수되어 이번 달에 완료된 요청은 넣지 않습니다. 이 정의를 표 아래에 남겨야 완료 건수가 분모인 접수 건수와 연결됩니다.

  • 대상: 사람 수인지, 요청 건수인지, 처리 횟수인지 구분합니다.
  • 기간: 접수일·완료일 중 어떤 날짜로 월을 구분하는지 씁니다.
  • 제외: 취소·중복·이월 건의 처리 기준을 기록합니다.
  • 출처: 파일 이름만 적지 말고 버전 또는 추출일과 해당 표·행도 남깁니다.

03표에서 문장으로 옮기는 순서

  1. 원자료를 보존하고 작업 사본을 만듭니다. 정렬과 필터를 바꾸기 전에 전체 행 수와 현재 필터를 기록합니다.
  2. 표의 제목과 각 열 이름에 대상·기간·단위를 씁니다. 다른 단위의 숫자는 먼저 환산한 뒤 같은 열에 둡니다.
  3. 합계와 소계의 포함 범위를 확인합니다. 상세행을 더한 합계에 소계를 다시 더하지 않습니다.
  4. 비율은 분자와 분모를 나란히 놓고 다시 계산합니다. 분모가 0이거나 없는 경우 0 %로 적지 말고 계산 불가 사유를 표시합니다.
  5. 계산 중에는 충분한 자릿수를 유지하고 표시 단계에서 정한 자릿수로 반올림합니다.
  6. 본문의 숫자와 표를 대조한 뒤 출처와 미확정 사항을 붙입니다. 숫자를 고쳤다면 제목·요약·차트 설명도 함께 찾아 고칩니다.

04직접 작성한 월간 실적표 예제

기간접수 건수완료 건수완료율
2026년 7월120건96건80.0 %
2026년 8월150건123건82.0 %
text
7월 완료율 = 96 ÷ 120 × 100 = 80.0 %
8월 완료율 = 123 ÷ 150 × 100 = 82.0 %
완료율 차이 = 82.0 − 80.0 = +2.0 %p
접수량 증가율 = (150 − 120) ÷ 120 × 100 = 25.0 %

문장 예시: “같은 달 접수 건을 기준으로 한 완료율은 7월 80.0 %에서 8월 82.0 %로 2.0 %p 높아졌다. 접수 건수는 120건에서 150건으로 25.0 % 늘었다.” 여기서 완료율의 상대 증가율 2.5 %와 완료율 차이 2.0 %p는 서로 다른 계산입니다. 보고 목적에 맞는 표현을 골라 이름을 붙입니다.

05숫자와 단위를 함께 바꾸기

원자료변환 계산문서 표기
길이 1.25 m1.25 × 1000길이 1250 mm
질량 2450 g2450 ÷ 1000질량 2.45 kg
온도 23.5 °C단위 변환 없음온도 23.5 °C

열 제목을 mm로 고치고 값 1.25를 그대로 두면 원래 길이와 1000배 다른 의미가 됩니다. 표 전체의 단위를 바꿀 때는 값, 열 제목, 각주, 본문을 함께 확인합니다. 표 안에 한 단위만 쓰면 각 셀에 기호를 반복하지 않고 “길이 (mm)”처럼 제목으로 알려줄 수 있습니다.

BIPM의 SI Brochure는 수치와 단위 기호 사이 공백, 단위 기호의 일관된 사용, 표의 같은 열에서 숫자 형식을 통일하는 원칙을 설명합니다. 23.5 °C처럼 쓰고, mm와 m 또는 MPa와 Pa를 구분합니다. 업무 문서의 금액·건수 표시는 조직 서식을 따르되, 통화와 천 원·백만 원 같은 배율은 명시합니다.

06완료 여부를 확인하는 방법

  1. source-data.json의 두 행에서 접수·완료 건수를 다시 읽습니다. 표의 120, 96, 150, 123과 하나씩 대조합니다.
  2. 완료율 두 개와 차이, 접수량 증가율을 독립적으로 계산합니다. 결과가 80.0 %, 82.0 %, 2.0 %p, 25.0 %인지 확인합니다.
  3. 합성 단위 예제 1.25 m = 1250 mm, 2450 g = 2.45 kg를 확인합니다.
  4. 문서에서 “완료율”, “접수”, “mm”, “kg”를 검색해 같은 수치가 다른 단위나 기간으로 반복되지 않았는지 봅니다.
  5. checklist.txt에 완료 표시를 남기고 해결되지 않은 기준은 담당자나 원자료로 확인합니다. 체크 표시가 원자료의 진위를 보장하지는 않습니다.

07자주 생기는 오류와 고치는 위치

증상원인고치는 방법
완료율 2 % 증가라고만 썼다상대 증가율과 %p 차이를 구분하지 않음계산식과 지표 이름을 함께 적음
빈칸을 전부 0으로 바꿨다미집계와 실적 0을 같은 뜻으로 처리원자료 상태를 확인하고 미확정 표시
합계가 원자료보다 크다소계와 상세행을 중복 합산집계 대상 행을 다시 지정
값이 맞는데 단위가 다르다표 제목만 수정값과 제목·본문의 변환을 함께 확인
표와 요약 숫자가 다르다수정본 일부만 반영문서 전체에서 같은 지표를 검색

08적용 범위와 내려받은 자료 사용법

이 점검은 숫자를 문서로 옮기는 과정의 오류를 찾는 절차입니다. 원자료의 누락, 업무 정의의 타당성, 측정 장비의 교정 상태까지 검증하지는 않습니다. 값이 상충하면 보기 좋은 쪽을 선택하지 말고 두 출처와 차이를 기록합니다. 법정 양식이나 계약에서 요구하는 단위·반올림 규정이 있으면 해당 기준을 별도로 확인해야 합니다.

  • README.txt: 연습 순서와 파일 설명
  • checklist.txt: 빈 점검표와 예제 정답
  • source-data.json: 합성 원자료와 단위 변환 예제
