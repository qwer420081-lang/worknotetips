AI로 어려운 이용안내를 쉬운 말로 고치기: 조건·예외·부정·기한 보존

가상의 자료 대여 안내 네 문장을 쉬운 표현으로 바꾸면서 등록회원 조건, 7일 기한, 예약자료 연장 불가, 비예약자료의 1회 연장 요청 가능과 승인 미확정이라는 핵심 조건을 잃지 않는 방법을 연습합니다.

이런 분께딱딱한 이용안내를 일반 독자가 이해하기 쉽게 바꾸고 싶지만 중요한 조건이나 예외가 사라질까 걱정되는 초보 일반인

준비사항
  • 원문을 문장별로 분리해 복사할 수 있으면 됩니다.
  • 아래 S1~S4는 법규가 아닌 완전한 가상 운영안내입니다.
  • 실제 회원정보나 개인정보를 입력할 필요가 없습니다.

01쉬운 말로 바꾸기 전에 반드시 남겨야 할 조건 표시하기

쉬운 말 편집의 목표는 내용을 줄이는 것이 아니라 같은 규칙을 더 쉽게 이해하도록 표현하는 것입니다. 따라서 문장을 고치기 전에 회원 조건, 기간, 금지 사항, 요청 가능 횟수, 승인 여부처럼 없어지면 의미가 달라지는 요소를 먼저 표시해야 합니다. 아래 내용은 실제 도서관이나 기관 규정이 아니라 튜토리얼용 가상 운영안내입니다.

입력 자료
S1 대여는 등록회원만 가능함.
S2 반납은 대여일 포함 7일 이내에 해야 함.
S3 예약자료는 연장할 수 없음.
S4 비예약자료는 반납 마감 전에 1회 연장을 요청할 수 있으나, 요청이 곧 연장 승인을 의미하는 것은 아님.
source ID반드시 보존할 요소바뀌면 안 되는 의미
S1등록회원만누구나 대여 가능으로 바꾸면 안 됨
S2대여일 포함, 7일 이내대여 다음 날부터 7일 등으로 계산 기준을 바꾸면 안 됨
S3예약자료, 연장 불가조건부 연장 가능으로 바꾸면 안 됨
S4비예약자료, 마감 전, 1회, 연장 요청 가능, 승인 미확정요청 가능을 자동 승인으로 바꾸면 안 됨

특히 S4는 한 문장 안에 여러 조건이 들어 있습니다. 쉬운 문장으로 나누는 것은 가능하지만 비예약자료라는 대상, 마감 전이라는 기한, 1회라는 횟수, 요청과 승인 사이의 차이를 모두 남겨야 합니다.

02쉬운 표현과 의미 보존을 동시에 요청하기

그냥 쉽게 써 달라고만 하면 조건이 생략될 수 있습니다. 따라서 어떤 내용을 반드시 보존해야 하는지 프롬프트에 직접 적습니다. 이번 실습에서는 짧은 문장과 일상적인 단어를 사용하되 새로운 혜택이나 예외를 만들지 않도록 제한합니다.

요청문
아래 가상 이용안내 S1~S4를 초보 이용자가 읽기 쉬운 말로 바꿔 주세요.

규칙:
- 각 source ID의 의미를 그대로 보존하세요.
- 조건, 예외, 부정 표현, 숫자, 기한을 삭제하거나 완화하지 마세요.
- S1의 등록회원만을 유지하세요.
- S2의 대여일 포함 7일 이내를 유지하세요.
- S3의 예약자료 연장 불가를 유지하세요.
- S4의 비예약자료, 반납 마감 전, 1회, 연장 요청 가능, 승인 확정 아님을 모두 유지하세요.
- 요청 가능을 승인됨 또는 자동 연장으로 바꾸지 마세요.
- 원문에 없는 수수료, 벌칙, 추가 연장, 예외를 만들지 마세요.

결과는 source ID별 쉬운 문장과 원문에서 보존한 핵심 조건을 함께 보여 주세요.

쉬운 표현은 문장 길이를 줄이거나 한 문장을 두 문장으로 나누는 방식으로 만들 수 있습니다. 그러나 원문보다 권리나 의무가 넓어지거나 좁아지면 단순 편집이 아니라 규칙 변경이 됩니다.

03원문과 쉬운 말 버전을 한 줄씩 대응시키기

아래 결과는 실제 서비스의 문장 변환 성능을 측정한 것이 아니라, 의미 보존 방식을 보여 주기 위해 AI 보조로 구성·검토한 편집 예시입니다. 쉬워 보이는지보다 먼저 원문 조건이 모두 남았는지 확인해야 합니다.

예시 결과
S1 쉬운 말: 자료는 등록회원만 빌릴 수 있습니다.
보존한 조건: 등록회원만 대여 가능

S2 쉬운 말: 빌린 날을 포함해 7일 안에 반납해야 합니다.
보존한 조건: 대여일 포함, 7일 이내

S3 쉬운 말: 예약된 자료는 대여 기간을 연장할 수 없습니다.
보존한 조건: 예약자료, 연장 불가

S4 쉬운 말: 예약되지 않은 자료는 반납 마감 전에 한 번 연장을 요청할 수 있습니다. 다만 요청했다고 해서 연장이 승인된 것은 아닙니다.
보존한 조건: 비예약자료, 마감 전, 1회, 요청 가능, 승인 미확정
ID원문 핵심쉬운 말 핵심보존 여부
S1등록회원만 가능등록회원만 빌릴 수 있음보존
S2대여일 포함 7일 이내빌린 날 포함 7일 안보존
S3예약자료 연장 불가예약된 자료는 연장할 수 없음보존
S4비예약자료는 마감 전 1회 연장 요청 가능, 승인 확정 아님예약되지 않은 자료는 마감 전 한 번 요청 가능, 요청만으로 승인되지 않음보존

04쉬워졌지만 규칙이 달라진 문장 찾아내기

가장 주의할 오류는 요청할 수 있다는 문장을 연장할 수 있다 또는 승인된다는 문장으로 바꾸는 것입니다. 표현상 작은 차이처럼 보여도 이용자에게 전달되는 조건은 크게 달라집니다. 기한 계산에서 대여일 포함이라는 말이 빠지는 것도 같은 종류의 문제입니다.

잘못된 결과
S2 쉬운 말: 자료는 빌린 다음 날부터 7일 동안 이용할 수 있습니다.

S4 쉬운 말: 예약되지 않은 자료는 반납일까지 한 번 자동으로 연장할 수 있습니다.
잘못된 부분원문과 달라진 점수정 방향
빌린 다음 날부터 7일S2의 대여일 포함 조건을 변경함빌린 날을 포함해 7일 안으로 복원
자동으로 연장S4의 요청 가능을 승인 또는 자동 처리로 바꿈한 번 연장을 요청할 수 있으나 승인 확정 아님으로 복원

쉬운 말 편집에서는 정보를 덜어 내는 것보다 논리 관계를 보존하는 일이 더 중요합니다. 만약 문장이 길어지더라도 요청과 승인의 차이를 설명하는 두 번째 문장을 남기는 편이 낫습니다.

05원문 자체가 애매하면 추측 대신 확인 질문 만들기

쉬운 말로 바꾸는 과정에서 원문에 정의되지 않은 부분을 발견할 수도 있습니다. 예를 들어 연장 요청이 어떤 기준으로 승인되는지는 S4에 적혀 있지 않습니다. 이런 경우 AI에게 규칙을 만들어 달라고 하지 말고 담당자에게 확인할 질문 목록을 만들어 달라고 요청할 수 있습니다.

요청문
S1~S4의 의미는 바꾸지 말고, 이용자가 추가로 궁금해할 수 있지만 원문만으로 답할 수 없는 확인 질문을 작성해 주세요.

조건:
- 원문에 없는 답을 추측하지 마세요.
- 질문만 작성하세요.
- 특히 S4의 연장 요청 승인 기준이나 처리 방식이 원문에 정의되어 있는지 구분하세요.
- 새로운 규정, 벌칙, 수수료, 예외를 만들지 마세요.
예시 결과
확인이 필요한 질문 예시:
1. 비예약자료의 연장 요청은 어떤 기준으로 승인되나요?
2. 연장 요청의 승인 여부는 이용자에게 어떤 방식으로 안내되나요?
3. 연장이 승인될 경우 새로운 반납 기한은 어떻게 정해지나요?

위 질문의 답은 S1~S4에 없으므로 별도 확인이 필요합니다.

확인 질문을 만든다고 해서 그 질문의 답까지 추정해서는 안 됩니다. 원문에 없는 부분을 미정으로 남기는 것이 잘못된 규칙을 만드는 것보다 낫습니다.

06쉬운 말보다 먼저 의미가 같은지 최종 확인하기

최종 검토에서는 원문과 쉬운 문장을 나란히 놓고 조건, 숫자, 기한, 부정 표현을 표시합니다. 자연스러운 문장인지 확인하는 단계는 그다음입니다. 특히 만, 이내, 불가, 요청, 승인 같은 단어는 의미 변화가 생기기 쉬우므로 따로 확인하는 것이 좋습니다.

확인 목록
[ ] S1에서 등록회원만이라는 조건이 남아 있는가?
[ ] S2에서 대여일 포함이라는 계산 기준이 남아 있는가?
[ ] S2의 7일이 다른 숫자로 바뀌지 않았는가?
[ ] S3에서 예약자료는 연장할 수 없다는 부정이 유지됐는가?
[ ] S4가 비예약자료에만 적용된다는 조건이 남아 있는가?
[ ] S4의 반납 마감 전이라는 기한이 남아 있는가?
[ ] S4의 연장 요청 횟수가 1회로 유지됐는가?
[ ] 요청 가능을 자동 승인이나 확정 승인으로 바꾸지 않았는가?
[ ] 원문에 없는 수수료, 벌칙, 예외, 승인 기준을 새로 만들지 않았는가?

실제 기관의 이용약관이나 법률 문서를 다룰 때는 담당자 검토와 별도 기준이 필요할 수 있습니다. 이 글은 그런 판단을 대신하지 않으며, 법규가 아닌 가상 운영안내를 통해 쉬운 말 편집에서 원문 의미를 보존하는 기본 절차만 연습합니다.

직접 확인할 항목

법규가 아닌 가상 운영안내 S1~S4를 대상으로 조건·기한·부정·요청과 승인의 차이가 쉬운 말 버전에서도 보존되는지 사람이 대조한 편집 예시

  • 등록회원만 조건이 유지됐는지 확인
  • 대여일 포함 7일 이내가 그대로인지 확인
  • 예약자료 연장 불가가 유지됐는지 확인
  • 비예약자료의 마감 전 1회 연장 요청 가능과 승인 미확정이 모두 보존됐는지 확인
  • 원문에 없는 규정이나 예외를 추가하지 않았는지 확인
검증 범위의 한계

결과 예시는 AI 보조로 구성·검토한 교육용 편집 예시이며 실제 기관 규정, 법률 해석, 특정 AI 제품의 변환 정확도나 최신 기능을 검증한 결과가 아닙니다.

AI로 문서 두 버전 비교하기: 변경·추가·삭제·동일 항목 구분

같은 행사의 안내문 V1과 V2를 AI에 함께 제공하고, 다섯 가지 비교 항목을 변경·추가·삭제·동일로 나누어 확인하는 실습입니다. 삭제된 문장을 임의로 해석하지 않고 문서에 실제로 적힌 차이만 기록하는 방법을 익힙니다.

AI로 공지문에서 FAQ 만들기: 원문에 없는 답은 확인 필요로 남기기

짧은 공지문을 바탕으로 여섯 개 FAQ를 만들면서, 근거가 있는 질문에는 source ID를 붙이고 요금·환불·대기처럼 원문에 없는 내용은 임의의 답을 만들지 않는 방법을 연습합니다.

AI로 자유서술 의견을 주제별로 묶기: 복수 라벨과 분류 보류 다루기

여섯 개의 짧은 자유서술 의견을 정해진 주제로 분류하고, 한 의견에 두 주제가 있으면 복수 라벨을 허용하는 실습입니다. 라벨 합계가 응답자 수보다 커질 수 있는 이유와 근거 없는 만족도·감정 강도 추론을 피하는 방법도 함께 확인합니다.

AI로 조사 질문과 검색 계획 만들기
