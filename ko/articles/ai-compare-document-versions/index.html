AI로 문서 두 버전 비교하기: 변경·추가·삭제·동일 항목 구분

같은 행사의 안내문 V1과 V2를 AI에 함께 제공하고, 다섯 가지 비교 항목을 변경·추가·삭제·동일로 나누어 확인하는 실습입니다. 삭제된 문장을 임의로 해석하지 않고 문서에 실제로 적힌 차이만 기록하는 방법을 익힙니다.

준비사항
  • 두 버전의 문서를 텍스트로 복사할 수 있으면 됩니다.
  • 실제 개인정보나 회사 내부자료 대신 아래 가상 자료만 사용합니다.
  • 프로그램 실행이나 코딩은 필요하지 않습니다.

01비교할 두 버전을 항목 ID와 함께 준비하기

문서 비교에서 가장 먼저 할 일은 V1과 V2의 문장을 섞지 않고 구분하는 것입니다. 이 실습에서는 가상의 행사 안내문을 사용하며, 각 문장에 A1~A4와 B1~B4라는 행 ID를 붙입니다. ID를 붙이면 AI가 어떤 문장을 근거로 판단했는지 사람이 다시 확인하기 쉽습니다. 아래 자료에는 개인정보가 없으며 모든 인물·행사·조건은 가상입니다.

입력 자료
[행사 안내 V1]
A1 행사 일시: 11월 14일 14시
A2 정원: 20명
A3 신청 마감: 11월 10일
A4 준비물: 노트

[행사 안내 V2]
B1 행사 일시: 11월 14일 15시
B2 정원: 24명
B3 신청 마감: 11월 10일
B4 온라인 참가: 제공하지 않음

두 버전에는 총 여덟 개의 행이 있지만 비교할 의미 단위는 정확히 다섯 개입니다. 행사 일시, 정원, 신청 마감, 준비물, 온라인 참가입니다. V1의 준비물 문장이 V2에 없다는 사실과 V2에 온라인 참가 문장이 새로 생겼다는 사실은 서로 다른 변화이므로 별도 항목으로 봅니다.

비교 항목V1 근거V2 근거비교할 내용
행사 일시A1B111월 14일은 같고 시각이 14시에서 15시로 바뀌었는지 확인
정원A2B220명과 24명을 비교
신청 마감A3B311월 10일이 그대로인지 확인
준비물A4해당 행 없음V2에서 항목이 사라졌는지 확인
온라인 참가해당 행 없음B4V2에서 새 항목이 추가됐는지 확인

02비교 기준을 프롬프트에 명시하기

단순히 두 문서를 비교해 달라고 하면 표현 차이와 의미 차이가 뒤섞일 수 있습니다. 이번 실습에서는 비교 항목을 정확히 다섯 개로 제한하고, 상태도 변경·추가·삭제·동일 중 하나로만 쓰게 합니다. 특히 V2에서 준비물 문장이 사라졌다고 해서 준비물이 필요 없다고 해석해서는 안 됩니다. 문서에 없는 이유는 알 수 없기 때문입니다.

요청문
아래 V1과 V2를 비교해 주세요.

비교 항목은 정확히 5개만 사용하세요.
1. 행사 일시
2. 정원
3. 신청 마감
4. 준비물
5. 온라인 참가

각 항목의 상태를 변경, 추가, 삭제, 동일 중 하나로 표시하세요. V1 근거 ID와 V2 근거 ID를 함께 적고, 차이를 한 문장으로 설명하세요.

중요 규칙:
- 문서에 없는 이유를 추측하지 마세요.
- V2에서 준비물 항목이 사라졌다고 해서 준비물이 필요 없다고 단정하지 마세요.
- 날짜와 숫자를 바꾸거나 보완하지 마세요.
- 근거가 없는 설명을 추가하지 마세요.

[자료]
V1: A1 행사 일시 11월 14일 14시 / A2 정원 20명 / A3 신청 마감 11월 10일 / A4 준비물 노트
V2: B1 행사 일시 11월 14일 15시 / B2 정원 24명 / B3 신청 마감 11월 10일 / B4 온라인 참가 제공하지 않음

프롬프트의 핵심은 무엇을 비교할지뿐 아니라 무엇을 하지 말아야 하는지도 적는 것입니다. 특히 삭제와 의미 변경은 다릅니다. 문장 삭제는 문서 상태에 대한 관찰이고, 필요 여부에 대한 판단은 별도의 정보가 있어야 가능합니다.

03결과 예시에서 다섯 항목을 하나씩 대조하기

아래 결과는 실제 AI 제품의 성능을 시험한 결과가 아니라, 이 튜토리얼에서 입력과 출력의 대응을 보여 주기 위해 AI 보조로 구성·검토한 편집 예시입니다. 독자는 표의 상태와 숫자를 원문과 직접 대조해야 합니다.

예시 결과
1. 행사 일시 — 변경
근거: A1, B1
11월 14일은 동일하지만 시작 시각이 14시에서 15시로 변경됨.

2. 정원 — 변경
근거: A2, B2
정원이 20명에서 24명으로 변경됨.

3. 신청 마감 — 동일
근거: A3, B3
신청 마감은 두 버전 모두 11월 10일임.

4. 준비물 — 삭제
근거: A4, V2 해당 행 없음
V1의 준비물 노트 항목이 V2에서는 확인되지 않음. 삭제 이유나 준비물 필요 여부는 자료만으로 판단할 수 없음.

5. 온라인 참가 — 추가
근거: V1 해당 행 없음, B4
V2에 온라인 참가를 제공하지 않는다는 항목이 새로 추가됨.
항목판정확인할 원문사람이 확인할 핵심
행사 일시변경A1 ↔ B114시가 15시로 바뀌었는지
정원변경A2 ↔ B220명이 24명으로 바뀌었는지
신청 마감동일A3 ↔ B3둘 다 11월 10일인지
준비물삭제A4 ↔ V2 없음노트가 V2에 없다는 사실만 적었는지
온라인 참가추가V1 없음 ↔ B4제공하지 않음이라는 부정 표현이 유지됐는지

04삭제된 항목을 임의로 해석하는 오류 찾기

문서 비교에서 위험한 오류는 원문 변화와 그 이유를 혼동하는 것입니다. V2에 준비물 문장이 없다는 것은 확인할 수 있지만, 주최자가 노트를 더 이상 요구하지 않는다고 결론 내릴 근거는 없습니다. 또 온라인 참가 항목은 단순 추가가 아니라 제공하지 않음이라는 부정 조건까지 보존해야 합니다.

잘못된 결과
준비물 — 변경
V2에서는 노트가 더 이상 필요하지 않으므로 준비하지 않아도 됩니다.

온라인 참가 — 추가
V2부터 온라인 참가가 가능합니다.

첫 문장은 삭제된 이유를 추측했고, 두 번째 문장은 B4의 의미를 정반대로 바꿨습니다. 올바른 기록은 준비물 항목이 V2에서 확인되지 않는다고만 쓰고, 온라인 참가는 제공하지 않음이라는 원문의 부정을 그대로 유지하는 것입니다.

잘못된 표현문제수정 원칙
노트가 더 이상 필요하지 않음삭제 이유를 임의로 추론함V2에서 준비물 항목이 확인되지 않는다고만 기록
온라인 참가가 가능함제공하지 않음이라는 부정을 반대로 바꿈온라인 참가를 제공하지 않음이라고 원문 그대로 유지

05문제가 있으면 전체 재작성이 아니라 오류 부분을 재요청하기

결과에서 한두 항목만 잘못됐다면 처음부터 다시 비교시키기보다 수정 범위를 지정하는 편이 검토하기 쉽습니다. 재요청할 때는 잘못된 항목, 원문 근거, 바꾸면 안 되는 사실을 함께 적습니다. 이렇게 하면 수정 전후를 사람이 직접 비교할 수 있습니다.

요청문
앞선 비교 결과 중 준비물과 온라인 참가 항목만 수정해 주세요.

수정 규칙:
- A4에는 준비물 노트가 있지만 V2에는 준비물 행이 없습니다. 따라서 상태는 삭제로 표시하고, 노트가 필요 없다는 추론은 제거하세요.
- B4는 온라인 참가 제공하지 않음입니다. 온라인 참가 가능으로 바꾸지 마세요.
- 나머지 행사 일시, 정원, 신청 마감 결과는 변경하지 마세요.
- 최종 결과는 정확히 5개 항목을 유지하세요.

이 재요청에서는 이미 맞는 세 항목을 고치지 말라고 명시했습니다. 수정 작업에서도 원문의 날짜, 시각, 정원 같은 값이 뜻하지 않게 변할 수 있으므로 마지막에 전체 다섯 항목을 다시 대조해야 합니다.

06원문을 보면서 최종 체크하기

AI의 비교 결과는 최종 판단표가 아니라 사람이 확인할 초안으로 사용합니다. 특히 변경 문서는 한 글자 차이보다 날짜, 숫자, 부정어, 추가·삭제 여부가 중요할 때가 많습니다. 아래 체크리스트를 원문 옆에 두고 하나씩 확인하면 됩니다.

확인 목록
[ ] 비교 항목이 행사 일시, 정원, 신청 마감, 준비물, 온라인 참가의 정확히 5개인가?
[ ] A1과 B1의 14시 → 15시 변경이 정확한가?
[ ] A2와 B2의 20명 → 24명 변경이 정확한가?
[ ] A3와 B3의 신청 마감 11월 10일이 동일로 표시됐는가?
[ ] A4가 V2에 없다는 사실을 삭제로 기록했는가?
[ ] 준비물 삭제를 필요 없음으로 해석하지 않았는가?
[ ] B4의 온라인 참가 제공하지 않음이라는 부정이 유지됐는가?
[ ] 원문에 없는 변경 이유나 정책을 새로 만들지 않았는가?

실제 업무 문서를 비교할 때도 같은 원칙을 적용할 수 있습니다. 먼저 비교 단위를 정하고, 각 문장에 식별자를 붙이고, AI가 제시한 상태를 다시 원문과 대조합니다. 민감한 실제 자료 대신 연습 단계에서는 가상 텍스트를 사용하는 편이 안전합니다.

직접 확인할 항목

가상의 행사 안내 V1·V2를 대상으로 입력 행 ID, 다섯 비교 항목, 숫자·날짜·부정 표현의 대응 관계를 사람이 읽어 검토한 편집 예시

  • 비교 항목 수가 정확히 5개인지 확인
  • A1~A4와 B1~B4의 값이 결과에서 바뀌지 않았는지 확인
  • 준비물 삭제를 필요 없음으로 추론하지 않았는지 확인
  • 온라인 참가 제공하지 않음의 부정 표현이 보존됐는지 확인
검증 범위의 한계

결과 예시는 AI 보조로 구성·검토한 교육용 편집 예시이며 특정 AI 제품에서 실제 실행하거나 정확도·성능을 검증한 결과가 아닙니다.

막연한 조사 목표를 사실 질문, 경험 질문, 결정 질문으로 나누고 무엇을 어디서 확인해야 하는지 검색 계획을 만드는 실습입니다. AI에게 검색 결과를 지어내게 하지 않고, 확인해야 할 자료와 미확인 항목을 먼저 구조화합니다.
