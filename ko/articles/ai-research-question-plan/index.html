AI로 조사 질문과 검색 계획 만들기

막연한 조사 목표를 사실 질문, 경험 질문, 결정 질문으로 나누고 무엇을 어디서 확인해야 하는지 검색 계획을 만드는 실습입니다. AI에게 검색 결과를 지어내게 하지 않고, 확인해야 할 자료와 미확인 항목을 먼저 구조화합니다.

이런 분께AI를 이용해 조사를 시작하고 싶지만 무엇부터 찾아야 할지 막막한 초보자

준비사항
  • 특정 AI 제품이나 최신 UI를 알 필요가 없습니다.
  • 실제 개인정보를 입력할 필요가 없습니다.
  • 독자가 조사하려는 지역과 조사 기준 날짜를 직접 정할 수 있어야 합니다.

01검색하기 전에 조사 목표와 이미 아는 사실을 분리하기

이번 실습의 가상 목표는 동네 도서관에서 평일 저녁 프로그램을 운영할 필요가 있는지 조사하는 것입니다. 처음부터 AI에게 결론을 물으면 확인되지 않은 수요나 예산을 사실처럼 섞을 수 있으므로, 먼저 주어진 정보와 아직 모르는 정보를 분리합니다. source ID는 이후 단계에서도 S1, S2, S3 그대로 유지합니다.

입력 자료
[가상 조사 메모]
S1: 검토 중인 프로그램은 60분짜리 평일 저녁 프로그램이다.
S2: 주요 대상은 성인 초보 이용자다.
S3: 실제 수요, 다른 시설의 운영 일정, 예산은 아직 확인하지 않았다.

주의:
- 검색은 아직 시작하지 않았다.
- 지역은 독자가 직접 정한다.
- 조사 기준 날짜도 독자가 직접 정한다.
- 확인되지 않은 통계, URL, 이용자 반응을 만들어서는 안 된다.

S1과 S2는 현재 검토 조건이고, S3는 미확인 항목입니다. 특히 '필요성이 있다'는 결론은 입력자료에 없습니다. 이 구분을 유지해야 이후 검색 결과와 인터뷰 결과를 같은 종류의 증거처럼 섞지 않을 수 있습니다.

source ID현재 상태내용조사에서의 역할
S1주어진 조건60분짜리 평일 저녁 프로그램 검토프로그램 형식과 시간 조건
S2주어진 조건대상은 성인 초보대상 이용자 범위
S3미확인실제 수요, 타 시설 일정, 예산추가 조사 필요

02목표를 사실 질문·경험 질문·결정 질문으로 나누기

같은 조사라도 질문 종류에 따라 확인 방법이 달라집니다. 운영시간과 기존 프로그램 일정은 공식 자료에서 확인할 수 있지만, 성인 초보 이용자가 왜 저녁 시간대를 선호하거나 피하는지는 이용자 경험을 직접 물어야 합니다. 마지막 결정 질문은 앞의 자료를 모은 뒤 판단하기 위한 질문으로 남겨 둡니다.

요청문
아래 가상 조사 메모만 이용해 조사 질문을 설계해 주세요.

S1: 검토 중인 프로그램은 60분짜리 평일 저녁 프로그램이다.
S2: 주요 대상은 성인 초보 이용자다.
S3: 실제 수요, 다른 시설의 운영 일정, 예산은 아직 확인하지 않았다.

요구사항:
1. 질문을 '사실 질문', '경험 질문', '결정 질문'으로 나눠 주세요.
2. 각 질문에 어떤 자료가 필요한지 적어 주세요.
3. 입력에 없는 사실, 통계, URL, 기관명은 만들지 마세요.
4. 검색을 이미 수행한 것처럼 쓰지 마세요.
5. S1, S2, S3 표기를 그대로 유지하세요.
6. 공식 운영자료와 이용자 인터뷰의 역할을 분리하세요.
예시 결과
[AI 보조로 구성·검토한 편집 예시 — 실제 제품 성능 검증 결과가 아님]

사실 질문
- 평일 저녁에 시설을 이용할 수 있는 운영시간은 어떻게 되는가?
- 현재 또는 최근에 성인 초보 대상 프로그램이 있었는가?
- 유사한 지역 시설에서는 평일 저녁 프로그램을 어떤 시간대에 운영하는가?

경험 질문
- 성인 초보 이용자가 프로그램에 참여할 때 시간대 선택에 영향을 주는 요인은 무엇인가?
- 60분이라는 길이가 참여하기에 부담스럽거나 적절한지 실제 이용자는 어떻게 느끼는가?

결정 질문
- 확인된 수요, 운영 가능 시간, 예산 조건을 함께 봤을 때 평일 저녁 프로그램을 추가 검토할 근거가 충분한가?

현재 확정된 것은 S1과 S2뿐이며, S3의 실제 수요·타 시설 일정·예산은 계속 미확인 상태다.
질문 종류예시 질문주요 확인 자료현재 답을 낼 수 있는가
사실 질문평일 저녁 운영이 가능한가?공식 운영시간·프로그램 안내아니오
사실 질문비슷한 시설은 언제 운영하는가?타 시설 공식 운영페이지아니오
경험 질문성인 초보는 어떤 시간대를 선택하는가?이용자 인터뷰아니오
경험 질문60분 길이를 어떻게 느끼는가?이용자 인터뷰아니오
결정 질문프로그램을 추가 검토할 근거가 충분한가?앞선 사실·경험 자료와 예산 확인아니오

03검색어 후보와 확인할 자료 종류를 계획하기

이 단계의 목적은 검색 결과를 얻는 것이 아니라 검색 전에 계획표를 만드는 것입니다. 지역명과 기준 날짜는 독자가 직접 넣습니다. 특히 '다른 도서관도 저녁 프로그램을 많이 한다'처럼 결론을 전제로 한 검색어보다 운영시간, 성인 프로그램, 저녁 일정처럼 확인 가능한 항목을 조합하는 편이 안전합니다.

확인 목적검색어 후보우선 확인 자료보조 자료검색 후 기록할 것
현재 시설 운영 가능 시간[지역명] 도서관 평일 운영시간해당 시설 공식 운영페이지공식 공지요일·운영시간·적용 날짜
성인 초보 프로그램 존재 여부[지역명] 도서관 성인 초보 프로그램공식 프로그램 안내공식 일정표프로그램명·대상·시간·게시일
타 시설 평일 저녁 일정[지역명] 도서관 성인 프로그램 저녁각 시설 공식 운영페이지공식 행사 안내요일·시작시각·진행시간·기준 날짜
이용자 경험검색어로 대체하지 않음이용자 인터뷰필요하면 익명 의견수렴반복되는 경험과 예외
예산 조건내부 확인 필요승인된 내부 자료담당자 확인확정 금액 또는 미정 상태

공식 운영페이지는 운영시간이나 일정 같은 공개 사실을 확인하는 역할을 맡고, 인터뷰는 실제 이용자의 경험을 확인하는 역할을 맡습니다. 두 자료가 서로 대체되지는 않습니다. 공식 페이지에 저녁 프로그램이 있다고 해서 수요가 높다고 단정할 수도 없고, 한 이용자가 저녁을 선호한다고 해서 전체 운영시간을 결정할 수도 없습니다.

04최신성 기준과 미확인 표를 먼저 정하기

운영시간과 프로그램 일정은 바뀔 수 있으므로 검색 전에 어떤 날짜를 기준으로 볼지 정해야 합니다. 여기서는 특정 최신 기간을 사실처럼 지정하지 않고, 독자가 조사 목적에 맞게 기준 날짜를 정하도록 합니다. 게시일이 없거나 현재 적용 여부를 확인할 수 없는 자료는 최신이라고 추정하지 않고 미확인으로 남깁니다.

항목최신성 확인 기준확인 실패 시 처리현재 상태
현재 시설 운영시간독자가 정한 기준 날짜에 적용되는 공식 안내인지 확인적용 날짜 불명으로 기록미확인
최근 프로그램 일정게시일과 행사일을 함께 확인과거 일정으로 별도 표시미확인
타 시설 운영 일정각 시설의 공식 페이지에서 날짜를 개별 확인현재 운영 여부 미확인으로 기록미확인
실제 수요인터뷰나 별도 조사 시점 기록인터뷰 미실시로 기록미확인
예산승인된 현재 자료 여부 확인예산 미정으로 유지미확인

이렇게 미확인을 명시하면 AI가 빈칸을 그럴듯한 숫자로 채우는 것을 발견하기 쉬워집니다. 조사계획 단계에서는 '답을 아직 모른다'는 상태 자체가 정상적인 결과입니다.

05잘못된 예시를 찾아 다시 요청하기

아래처럼 검색하지 않은 내용을 이미 확인한 것처럼 쓰거나, 입력에 없는 비율과 URL을 생성하면 조사계획으로 사용할 수 없습니다. 특히 정확해 보이는 숫자나 링크가 포함되어 있어도 출처를 실제로 확인하기 전에는 증거가 아닙니다.

잘못된 결과
[잘못된 편집 예시]
지역 성인의 72%가 평일 저녁 프로그램을 원하며, 주변 도서관 5곳도 모두 오후 7시에 유사 프로그램을 운영한다. 따라서 60분 저녁 프로그램은 수요가 충분하다. 자세한 통계는 https://example.invalid/library-survey 에서 확인할 수 있다.

문제는 네 가지입니다. 입력자료에 72%라는 통계가 없고, 주변 시설 5곳을 조사했다는 기록도 없으며, 오후 7시라는 운영시간도 제공되지 않았습니다. URL 역시 실제 확인 자료가 아닙니다. 또한 S3에서 수요가 미확인이라고 명시했는데도 결론을 먼저 확정했습니다.

요청문
방금 답변을 다시 작성해 주세요.
- 검색을 수행했다는 표현을 모두 제거하세요.
- 입력에 없는 숫자, 시설 수, 시간, URL을 삭제하세요.
- S1, S2는 주어진 조건으로 유지하세요.
- S3의 실제 수요, 타 시설 일정, 예산은 '미확인'으로 유지하세요.
- 결과 대신 사실 질문·경험 질문·결정 질문, 검색어 후보, 확인할 자료 종류, 최신성 기준을 제시하세요.
- 공식 운영페이지와 이용자 인터뷰의 역할을 분리하세요.

06실제 검색 전 독자가 확인할 체크리스트

계획이 완성되면 바로 결론을 내리지 말고 아래 항목을 직접 확인합니다. 그다음 독자가 정한 지역과 기준 날짜로 실제 공식 자료를 확인하고, 경험 질문은 별도 인터뷰로 조사합니다. 이 글의 결과 예시는 AI 보조로 구성·검토한 편집 예시이며 실제 AI 제품의 검색 성능이나 조사 정확도를 검증한 결과가 아닙니다.
