AI로 무리 없는 주간 계획 만들기: 가능한 시간부터 계산하기

할 일을 먼저 빈 시간에 억지로 넣는 대신 일주일의 실제 가용시간과 필요한 작업시간을 먼저 계산하는 방법을 연습합니다. 계획 도중 수요일 시간이 사라지는 상황까지 다루며 AI가 존재하지 않는 추가 시간을 만들어내지 않도록 검수합니다.

이런 분께개인 공부나 생활 할 일을 현실적인 시간 범위 안에서 배치하고 싶은 비개발자

준비사항
  • 일주일 동안 실제로 사용할 수 있는 시간을 분 단위로 적을 수 있을 것
  • 작업별 예상 소요시간과 필요한 횟수를 대략 정할 수 있을 것
  • 실제 업무 로그나 고객 일정이 아닌 개인용 가상 예제로 연습할 것

01할 일보다 먼저 가용시간을 계산하기

이번 실습의 핵심은 AI에게 '이번 주 계획 짜줘'라고 바로 요청하지 않고, 먼저 사용 가능한 시간을 숫자로 고정하는 것입니다. 가용시간은 월 30분, 화 0분, 수 45분, 목 30분, 금 0분, 토 60분, 일 30분입니다.

요일가용시간
월30분
화0분
수45분
목30분
금0분
토60분
일30분

합계는 30+0+45+30+0+60+30=195분입니다. 이 숫자가 일주일 동안 사용할 수 있는 최대 용량입니다. 화요일과 금요일은 0분이므로 어떤 작업도 배정하지 않는 것이 기본 조건입니다.

02작업시간과 횟수를 따로 계산하기

이번 주 할 일은 서류정리 20분을 2회, 독서 25분을 3회, 발표연습 30분을 2회입니다. 각 작업의 총시간을 먼저 계산하면 서류정리 40분, 독서 75분, 발표연습 60분으로 전체 175분입니다.

작업1회 시간횟수총시간
서류정리20분2회40분
독서25분3회75분
발표연습30분2회60분
합계175분

가용시간 195분에서 필요한 시간 175분을 빼면 20분의 여유가 있습니다. 따라서 현재 조건에서는 모든 작업을 넣을 수 있지만, 아무 날에나 배치할 수 있다는 뜻은 아닙니다. 각 요일의 최대시간도 동시에 지켜야 합니다.

03모호한 요청이 만드는 과한 계획 살펴보기

요청문
이번 주에 서류정리, 독서, 발표연습을 해야 해. 골고루 계획 짜줘.

이 요청에는 요일별 가용시간과 작업 횟수가 없기 때문에 AI가 보기 좋은 계획을 임의로 만들 가능성이 있습니다. 다음은 일부러 문제가 있도록 만든 가상 AI 답변이며 실제 실행 결과가 아닌 편집 예시입니다.

편집 예시
[편집 예시 · 실제 AI 응답 아님]
월: 서류정리 20분 + 독서 25분
화: 발표연습 30분
수: 독서 25분
목: 서류정리 20분 + 발표연습 30분
금: 독서 25분
토·일: 부족한 작업 보충

월요일에는 45분을 넣어 가용시간 30분을 넘겼고, 화요일과 금요일은 실제 가용시간이 0분인데 작업을 배정했습니다. '골고루'라는 표현만으로는 현실적 제약이 전달되지 않는다는 것을 보여주는 예입니다.

04합계와 요일 한도를 함께 주고 계획 받기

요청문
개인 주간 계획을 만들어줘.
가용시간은 월30분, 화0분, 수45분, 목30분, 금0분, 토60분, 일30분이고 합계는 195분이야.
할 일은 서류정리 20분×2회, 독서 25분×3회, 발표연습 30분×2회로 총 175분이야.
각 요일의 가용시간을 넘기지 말고, 화요일과 금요일에는 아무 작업도 넣지 마. 작업 횟수도 정확히 지켜줘. 20분의 여유시간은 억지로 채우지 말고 남겨둬.
표 형태로 요일별 작업과 사용시간을 보여주고 마지막에 총 사용시간과 남은 시간을 다시 계산해줘.

다음은 조건을 만족하는 허용 가능한 배치의 편집 예시입니다. 실제 AI 실행 결과가 아닙니다.

요일배치사용시간가용시간
월독서 1회25분30분
화휴식0분0분
수서류정리 1회 + 독서 1회45분45분
목발표연습 1회30분30분
금휴식0분0분
토발표연습 1회 + 독서 1회55분60분
일서류정리 1회20분30분

사용시간은 25+45+30+55+20=175분이고 전체 가용시간 195분보다 20분 적습니다. 서류정리 2회, 독서 3회, 발표연습 2회도 정확히 충족합니다.

05보기 좋은 계획보다 산술 조건을 먼저 검수하기

  • 월 25분은 최대 30분 이하인지 확인
  • 수 45분은 최대 45분 이하인지 확인
  • 목 30분은 최대 30분 이하인지 확인
  • 토 55분은 최대 60분 이하인지 확인
  • 일 20분은 최대 30분 이하인지 확인
  • 화요일과 금요일 사용시간이 0분인지 확인
  • 전체 가용시간 합계가 195분인지 다시 계산
  • 전체 작업시간 합계가 175분인지 다시 계산
  • 서류정리 2회, 독서 3회, 발표연습 2회인지 횟수 확인
  • 195-175=20분의 여유가 실제로 남는지 확인

AI가 표를 깔끔하게 만들더라도 위 검산 중 하나라도 맞지 않으면 계획을 수정해야 합니다. 특히 작업을 두 개 이상 넣은 날은 합산 시간이 하루 최대치를 넘지 않는지 직접 더해보는 것이 중요합니다.

요청문
이 계획을 다시 검산해줘. 각 요일 사용시간이 가용시간을 넘는지, 전체 작업시간이 175분인지, 작업 횟수가 서류정리2·독서3·발표연습2인지 항목별로 확인해줘. 단, 네 검산 결과도 내가 직접 다시 계산할 수 있도록 덧셈식을 함께 보여줘.

06수요일 45분이 사라지면 무엇을 포기할지 결정하기

계획을 만든 뒤 수요일 45분을 갑자기 사용할 수 없게 되었다고 가정합니다. 새 가용시간은 기존 195분에서 45분을 뺀 150분입니다. 원래 할 일은 175분이므로 25분이 부족합니다. 따라서 원래 작업을 모두 넣는 계획은 산술적으로 불가능합니다.

요청문
수요일 45분을 갑자기 사용할 수 없게 됐어. 다른 요일의 가용시간은 그대로 유지하고 추가 시간을 임의로 만들지 마. 이제 총 가용시간이 150분인데 기존 할 일은 175분이야. 무엇을 조정해야 하는지 먼저 설명하고, 가능한 선택안을 보여줘. 작업을 쪼개서 배치해도 되는지는 내가 아직 정하지 않았으니 필요하면 그 조건도 확인해줘.

다음은 수정 원리를 보여주기 위한 편집 예시입니다. 실제 AI 응답이 아닙니다.

편집 예시
[편집 예시 · 실제 AI 응답 아님]
수요일을 제외하면 가용시간은 150분이라 기존 작업 175분을 모두 배치할 수 없습니다. 최소 25분을 줄이거나 다음 주로 미뤄야 합니다. 한 가지 선택은 독서 1회 25분을 다음 주로 미루는 것입니다. 그러면 남은 작업시간은 150분이 되어 총 가용시간과 정확히 같아집니다. 다만 남은 작업을 각 요일 한도 안에 배치할 때 작업을 더 작은 단위로 나눠도 되는지 여부에 따라 가능한 배치가 달라질 수 있으므로, 분할 허용 여부를 먼저 확인하는 것이 좋습니다.

여기서 중요한 것은 AI가 토요일을 85분으로 늘리거나 화요일에 새 시간을 만드는 식으로 문제를 숨기지 않는 것입니다. 부족한 시간이 생기면 먼저 '모두 할 수 없다'는 사실을 인정하고, 우선순위를 조정해야 합니다. 독서 1회 25분을 다음 주로 미루면 남은 작업은 정확히 150분이므로 총량 기준으로는 배치 가능해집니다. 다만 실제 요일별 배치는 작업을 분할할 수 있는지에 따라 달라질 수 있으므로 그 조건을 사용자에게 확인해야 합니다.

직접 확인할 항목

텍스트 대화만 사용하는 편집 예시 · 실제 AI 응답은 도구·모델에 따라 달라짐

  • 요일별 가용시간 합계가 195분인지 직접 계산
  • 원래 작업 총시간이 175분인지 작업별 시간×횟수로 계산
  • 원래 계획에서 각 요일 사용시간이 해당 요일 최대시간을 넘지 않는지 확인
  • 화요일과 금요일에 작업이 배정되지 않았는지 확인
  • 서류정리 2회, 독서 3회, 발표연습 2회가 정확히 배치됐는지 확인
  • 원래 계획에 20분의 여유가 남는지 확인
  • 수요일 45분 제거 후 전체 가용시간이 150분인지 확인
  • 150분으로 175분의 작업을 모두 수행할 수 없음을 확인
  • 독서 1회 25분을 다음 주로 미루면 남은 작업시간이 150분이 되는지 확인
  • AI가 존재하지 않는 추가 시간을 임의로 만들지 않았는지 확인
검증 범위의 한계

실제 일정관리 도구에서 실행하거나 사용자 행동을 시험한 결과가 아니라 개인 계획 학습을 위한 편집 예시입니다. 예상 소요시간은 실제 상황에서 달라질 수 있으며, 작업 분할 가능 여부와 우선순위는 사용자가 직접 결정해야 합니다.
