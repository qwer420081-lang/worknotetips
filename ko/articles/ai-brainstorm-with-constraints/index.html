제약조건을 정해 AI로 아이디어 발상하기

참가 인원, 시간, 인쇄물, 구매 가능 여부, 사용 장비처럼 제약조건을 먼저 고정한 뒤 AI에게 서로 다른 대안 4개를 발상하게 하는 실습입니다. 어느 아이디어가 가장 좋은지 결정하는 대신 각 대안이 조건을 지키는지 확인하고, 조건이 바뀌었을 때 다시 요청하는 방법을 다룹니다.

이런 분께막연한 아이디어 목록보다 현실적인 조건을 반영한 여러 대안을 얻고 싶은 초보자

준비사항
  • 실제 구매나 장비 사용 없이 가상 활동을 설계합니다.
  • 실행프로그램 코드는 사용하지 않습니다.
  • 아이디어의 실현 가능성을 AI가 보장한다고 가정하지 않습니다.

01아이디어보다 먼저 바꿀 수 없는 조건 적기

이번 가상 과제는 도서관의 초보 독서 활동을 설계하는 것입니다. 브레인스토밍에서는 먼저 '좋은 아이디어를 많이 내줘'라고 요청하기보다 실제로 지켜야 하는 조건을 고정하는 편이 결과를 검토하기 쉽습니다. 여기서는 참가 8명, 총 30분, 인쇄물 최대 16장, 추가 구매 없음, 장비는 종이와 펜만이라는 조건을 사용합니다.

입력 자료
[가상 활동 설계 조건]
S1: 참가자는 8명이다.
S2: 전체 활동 시간은 총 30분이다.
S3: 인쇄물은 최대 16장까지 사용할 수 있다.
S4: 추가 구매는 하지 않는다.
S5: 사용할 수 있는 장비는 종이와 펜뿐이다.

목표: 초보자가 참여할 수 있는 독서 활동 대안 4개를 발상한다.
주의: 가장 좋은 안을 고르는 과제가 아니라 서로 다른 대안을 만드는 과제다.

02서로 다른 방식의 대안 4개를 요청하기

AI는 조건을 주지 않으면 비슷한 형식의 아이디어를 여러 이름으로 반복할 수 있습니다. 따라서 네 아이디어가 활동 방식 자체에서 달라야 한다고 명시하고, 각각 진행 순서·분 단위 시간·인쇄물 수·미확인 조건을 함께 적도록 요청합니다.

요청문
다음 제약을 모두 지키는 초보 독서 활동 아이디어 4개를 만들어 주세요.

S1: 참가 8명
S2: 총 30분
S3: 인쇄물 최대 16장
S4: 추가 구매 없음
S5: 종이와 펜만 사용

요구사항:
1. 네 아이디어는 활동 방식이 서로 달라야 합니다.
2. 각 아이디어마다 진행 순서를 단계별로 적고 각 단계의 시간을 분 단위로 표시하세요.
3. 단계별 시간 합계를 정확히 30분으로 적으세요.
4. 필요한 인쇄물 총수를 적고 16장 이하인지 확인하세요.
5. 실행 전에 사람이 확인해야 할 미확인 조건을 최소 1개 적으세요.
6. 장비나 재료를 임의로 추가하지 마세요.
7. 어느 안이 가장 좋다는 결론이나 순위를 만들지 마세요.
8. 실현 가능성이 보장된다고 표현하지 마세요.

이 요청은 아이디어 생성과 조건 검사를 함께 요구하지만 실제 공간, 참가자의 읽기 수준, 준비 가능한 문서의 내용은 아직 확인하지 않습니다. 따라서 결과에 '미확인 조건' 열을 남기는 것이 중요합니다.

03네 가지 편집 예시의 시간과 인쇄물 수 확인하기

아래 네 대안은 서로 다른 활동 구조를 보여 주기 위한 편집 예시입니다. 모든 안은 30분으로 맞추고 인쇄물은 16장 이하로 제한했지만, 실제 참가자에게 적합한지나 현장에서 원활하게 진행되는지는 검증하지 않았습니다.

예시 결과
[AI 보조로 구성·검토한 편집 예시 — 실제 실행 성능 검증이 아님]

아이디어 A: 한 문장 표시와 짝 설명
- 5분: 짧은 글을 읽고 마음에 남는 한 문장 표시
- 8분: 각자 선택 이유 메모
- 10분: 2명씩 짝을 이루어 서로 설명
- 5분: 각 짝에서 공통점 1개 기록
- 2분: 마무리
합계 30분
인쇄물: 참가자용 글 8장
미확인: 준비한 글의 난이도가 초보자에게 적절한지 확인 필요

아이디어 B: 질문 카드 직접 만들기
- 5분: 짧은 글 읽기
- 7분: 각자 질문 1개를 종이에 작성
- 10분: 4명씩 두 조로 질문을 돌려 답하기
- 6분: 각 조에서 기억에 남는 질문 1개 정리
- 2분: 마무리

미확인: 참가자가 질문 작성 방식에 익숙한지 확인 필요

아이디어 C: 인쇄물 없이 공동 요약문 만들기
- 5분: 진행자가 준비한 짧은 글을 한 문장씩 읽어 주고 참가자는 핵심어 메모
- 8분: 각자 핵심어 3개 선택

- 5분: 두 조가 요약문을 서로 읽기
- 2분: 마무리
합계 30분
인쇄물: 0장
미확인: 진행자가 읽어 줄 텍스트를 사전에 적절히 준비할 수 있는지 확인 필요

아이디어 D: 장면 순서 다시 구성하기
- 4분: 짧은 이야기 읽기
- 6분: 각자 핵심 장면 3개 메모
- 10분: 4명씩 두 조에서 장면 순서를 논의
- 8분: 각 조가 선택한 순서와 이유를 종이에 정리
- 2분: 마무리
합계 30분
인쇄물: 읽기자료 8장
미확인: 사용할 이야기가 장면 순서를 논의하기에 적합한지 확인 필요

04아이디어의 재미보다 제약 위반부터 검사하기

브레인스토밍 결과를 받을 때는 먼저 재미있어 보이는지를 판단하기보다 숫자와 조건부터 확인합니다. 이 실습에서는 각 안의 시간 합계가 30분을 넘지 않는지, 인쇄물이 16장을 넘지 않는지, 추가 장비와 구매품이 들어가지 않았는지를 확인합니다.

여기서 '예시상 없음'은 실제 현장에서 추가 준비물이 절대 필요하지 않다는 뜻이 아닙니다. 작성된 활동안 안에서 추가 품목을 요구하지 않았다는 뜻뿐입니다. 공간, 소음, 참가자의 읽기 수준 같은 현장 조건은 사람이 별도로 확인해야 합니다.

05조건을 어긴 답과 제약 수정 재요청 방법

AI가 흥미로운 아이디어를 만들면서도 숫자 제약을 놓칠 수 있습니다. 이때 전체 아이디어를 버리기보다 어떤 조건이 위반되었는지 지정하고 해당 조건만 수정하도록 요청할 수 있습니다. 또한 실제 상황에서 제약 자체가 바뀌었다면 변경된 값만 명확하게 알려 주고 나머지는 그대로 유지하게 합니다.

잘못된 결과
[잘못된 편집 예시]
활동 E: 참가자 8명에게 컬러 카드 3장씩 배부하고 태블릿으로 책 표지를 검색한다.
- 설명 5분
- 개인 검색 10분
- 조별 활동 12분
- 발표 8분
합계 35분
필요 인쇄물: 활동지 24장
준비물: 컬러 카드, 태블릿, 종이, 펜

이 답은 S2의 30분을 5분 초과하고, S3의 인쇄물 최대 16장을 8장 초과합니다. 또한 S4의 추가 구매 없음과 S5의 종이·펜만 사용 조건에도 맞지 않는 준비물이 들어갔습니다. 아이디어의 내용이 흥미로운지와 별개로 제약 위반이므로 그대로 사용할 수 없습니다.

요청문
방금 아이디어를 제약조건에 맞게 수정해 주세요.
- 참가자 8명은 유지하세요.
- 총 시간은 30분 이내로 다시 계산하세요.
- 인쇄물은 16장 이내로 줄이세요.
- 추가 구매가 필요한 재료는 모두 제거하세요.
- 종이와 펜 외의 장비는 제거하세요.
- 수정 후 단계별 시간 합계와 인쇄물 총수를 다시 표시하세요.
- 실현 가능성이 보장된다고 표현하지 말고 미확인 조건을 남기세요.

만약 제약 자체를 바꾸는 경우에는 내가 바꾼 조건만 변경하고 나머지 S1~S5는 그대로 유지하세요.

06선택 전에 독자가 직접 확인할 체크리스트

이 글의 목적은 네 대안 중 하나를 추천하거나 순위를 정하는 것이 아닙니다. 먼저 조건을 지킨 서로 다른 안을 확보하고, 이후 실제 공간이나 참여자 상황을 확인한 사람이 필요에 맞게 선택하거나 다시 수정하는 데 있습니다. 아래 결과 예시는 AI 보조로 구성·검토한 편집 예시이며 실제 활동의 만족도, 참여율, 교육효과 또는 AI 제품 성능을 검증한 결과가 아닙니다.

직접 확인할 항목

편집 예시 검토 범위: 참가 8명, 총 30분, 인쇄물 최대 16장, 추가 구매 없음, 종이와 펜만 사용이라는 제약을 네 대안의 시간·인쇄물 수와 대조했습니다.

  • 아이디어 4개 구성
  • 각 아이디어 시간 합계 30분 확인
  • 인쇄물 수 8장·16장·0장·8장으로 모두 16장 이하
  • 추가 구매 요구 없음
  • 종이와 펜 외 장비 요구 없음
  • 각 아이디어에 미확인 조건 포함
  • 순위나 최종 선택 결론을 제시하지 않음
검증 범위의 한계

실제 도서관이나 참가자에게 활동을 실행하지 않았으며 실현 가능성, 만족도, 효과, 안전성 또는 AI 제품 성능을 검증하지 않았습니다. 실제 사용 전에는 공간, 참가자의 특성, 준비 가능한 자료를 사람이 직접 확인해야 합니다.

AI로 자유서술 의견을 주제별로 묶기: 복수 라벨과 분류 보류 다루기

여섯 개의 짧은 자유서술 의견을 정해진 주제로 분류하고, 한 의견에 두 주제가 있으면 복수 라벨을 허용하는 실습입니다. 라벨 합계가 응답자 수보다 커질 수 있는 이유와 근거 없는 만족도·감정 강도 추론을 피하는 방법도 함께 확인합니다.

AI로 어려운 이용안내를 쉬운 말로 고치기: 조건·예외·부정·기한 보존

AI로 조사 질문과 검색 계획 만들기

막연한 조사 목표를 사실 질문, 경험 질문, 결정 질문으로 나누고 무엇을 어디서 확인해야 하는지 검색 계획을 만드는 실습입니다. AI에게 검색 결과를 지어내게 하지 않고, 확인해야 할 자료와 미확인 항목을 먼저 구조화합니다.

AI로 이용자 조사 인터뷰 질문 만들기

가상 신청서 이용 경험을 조사하기 위한 15분 인터뷰 질문을 AI와 설계하는 실습입니다. 유도질문을 최근 실제 행동에 대한 중립 질문으로 고치고, 아직 실시하지 않은 인터뷰의 예상 답변을 실제 증거처럼 쓰지 않는 방법을 다룹니다.
