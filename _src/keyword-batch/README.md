# Presentation and reporting update — 2026-09-23

One new tutorial, `ai-presentation-outline`, and additions to two existing reporting tutorials, in en/ko/ja/es/pt-BR. The JSON files contain the reviewed article and authoritative localized report patches. Original report examples and verification records are preserved; run `tools/build_keyword_articles.py` after any earlier generator that rewrites those reports.

Drafts and translations were requested through ordinary Chat, not Work. They were reviewed for source traceability, percentage denominators, unsupported claims, and translation structure. Survey source wording was clarified to specify that the 12 respondents were among the 18 attendees and answered once. Page titles and descriptions were edited to address the reader rather than describe the editing task.

The six-slide result is an editorial demonstration, not a benchmark of a presentation product. No PPTX generator or real organization data was tested. Numerical checks use local Python fractions: 18/24 = 75%, 9/12 = 75%; unknown attendee responses must not be converted to negative responses. Site tests verify preserved code, localized prompts, six-row tables, canonical/hreflang routes, and copy targets.

Research basis: Google Trends, South Korea, past 12 months, web search, all categories, viewed 2026-09-23.
