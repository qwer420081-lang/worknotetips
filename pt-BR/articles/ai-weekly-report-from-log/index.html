Uso de IA no trabalho

Transformar um registro diário de trabalho em relatório semanal com IA e conferir os números

Um assistente de chat com IA pode transformar anotações diárias curtas em um relatório semanal legível, mas totais como horas e atividades concluídas devem ser conferidos separadamente. Este guia usa um pequeno registro sintético, um pedido para a IA e um script de conciliação em Python.

Para quem éPara quem mantém registros diários curtos e quer usar IA para redigir relatórios semanais sem perder o controle sobre horas, contagens e dados factuais.

Preparação
  • Python 3.12
  • Um arquivo CSV simples contendo o registro diário de trabalho

01Por que conferir os números de um relatório semanal escrito por IA?

A IA é útil para reorganizar anotações curtas de trabalho em um texto legível, mas não deve ser tratada como fonte de verdade para cálculos. Um relatório semanal pode parecer coerente e ainda assim alterar um total, contar uma atividade duas vezes ou apresentar uma tarefa planejada como concluída. Um fluxo mais seguro separa a redação narrativa da conciliação numérica.

  • Use o registro de trabalho como fonte factual.
  • Peça à IA para resumir apenas o que aparece no registro.
  • Calcule horas e contagens separadamente a partir dos dados estruturados.
  • Compare o relatório da IA com os totais calculados de forma independente.
  • Corrija o relatório antes de enviá-lo ou publicá-lo.
Texto e aritmética são verificações diferentes

Um relatório pode estar bem escrito e ainda conter totais incorretos. Trate a qualidade da redação e a precisão numérica como etapas separadas de revisão.

Calculando manualmente, as horas são 2.0 + 1.5 + 2.5 + 1.0 + 2.0 + 1.5 = 10.5 horas. Cinco das seis atividades têm status completed, então a quantidade de atividades concluídas é 5. A última atividade ainda está in progress e não deve ser contada como concluída.

03Pedir à IA que redija a partir do registro, não da memória

Cole o registro em um assistente de chat com IA e limite explicitamente a tarefa à reorganização e redação dos dados fornecidos. Peça também que a IA informe os totais para que eles possam ser conferidos depois.

Pedido à IA: usando apenas o registro de trabalho abaixo, escreva um relatório semanal conciso com três partes: trabalho concluído, trabalho ainda em andamento e totais da semana. Não invente resultados nem tarefas. Informe o total de horas registradas e o número de atividades concluídas. Preserve o significado original das tarefas.

Uma resposta típica da IA poderia dizer: nesta semana, os dados de clientes foram limpos, um script de importação foi elaborado e testado, IDs duplicados foram investigados e as regras de validação foram atualizadas. As anotações para usuários continuam em andamento. O tempo total registrado foi de 10.5 horas, com 5 atividades concluídas.

Ainda não confie em um total que parece correto

Mesmo que a IA informe 10.5 horas e 5 atividades concluídas, calcule esses valores de forma independente a partir do registro antes de aceitar o relatório.

Salve o mesmo exemplo sintético como work_log.csv com as colunas date, task, hours e status. O script de conciliação deve ler diretamente esse arquivo-fonte, em vez de tentar recuperar números do texto escrito pela IA.

Essa separação é importante: o CSV é a evidência, enquanto o relatório semanal é uma apresentação dessa evidência.

05Recalcular horas e contagens com Python

O script a seguir para Python 3.12 lê work_log.csv, valida os campos obrigatórios, soma as horas, conta os status e grava um relatório de conciliação em outputs/weekly_reconciliation.txt. Ele não sobrescreve um diretório outputs existente.

python
from pathlib import Path
import csv

input_path = Path("work_log.csv")
output_dir = Path("outputs")

if output_dir.exists():
    raise SystemExit("outputs already exists; remove or rename it before running again")

if not input_path.exists():
    raise SystemExit("work_log.csv was not found")

required_fields = {"date", "task", "hours", "status"}
rows = []

with input_path.open("r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)

    if reader.fieldnames is None:
        raise SystemExit("CSV has no header")

    missing = required_fields - set(reader.fieldnames)
    if missing:
        raise SystemExit(f"Missing columns: {sorted(missing)}")

    for line_number, row in enumerate(reader, start=2):
        try:
            hours = float(row["hours"])
        except ValueError:
            raise SystemExit(f"Invalid hours value on line {line_number}")

        if hours < 0:
            raise SystemExit(f"Negative hours on line {line_number}")

        status = row["status"].strip().lower()
        if status not in {"completed", "in progress"}:
            raise SystemExit(f"Unexpected status on line {line_number}: {status}")

        rows.append({
            "date": row["date"].strip(),
            "task": row["task"].strip(),
            "hours": hours,
            "status": status,
        })

total_hours = sum(row["hours"] for row in rows)
completed_count = sum(row["status"] == "completed" for row in rows)
in_progress_count = sum(row["status"] == "in progress" for row in rows)

output_dir.mkdir()
report_path = output_dir / "weekly_reconciliation.txt"

report = (
    f"Rows: {len(rows)}\n"
    f"Total hours: {total_hours:.1f}\n"
    f"Completed activities: {completed_count}\n"
    f"In-progress activities: {in_progress_count}\n"
)

report_path.write_text(report, encoding="utf-8")

print(report, end="")
print(f"Saved: {report_path}")

  1. Compare cada número do relatório da IA com a saída da conciliação.
  2. Confirme que atividades concluídas e em andamento não foram misturadas.
  3. Compare a descrição das tarefas com o registro original para verificar se nenhum resultado foi inventado.
  4. Se o total da IA for diferente, use o cálculo do registro estruturado e revise o texto.

07Erros comuns e limitações

  • Somar os números do relatório da IA em vez de usar o registro original.
  • Contar todas as linhas como concluídas mesmo quando algumas ainda estão em andamento.
  • Tratar várias linhas do mesmo projeto como uma única tarefa sem definir essa regra de contagem.
  • Permitir que a IA deduza resultados que não estejam registrados explicitamente.
  • Alterar a forma de escrever os status no registro sem atualizar os valores aceitos pelo script.
  • Ignorar linhas ausentes, valores de horas inválidos ou entradas duplicadas antes de calcular os totais.

Este exemplo conta atividades concluídas por linha. Em uma organização real, a contagem pode usar tickets, entregáveis, projetos ou marcos, portanto a regra deve ser definida antes da conciliação. O script também verifica apenas aritmética e status simples; ele não consegue determinar se uma entrada do registro é verdadeira nem se a qualidade do trabalho realizado foi suficiente.

Limites da verificação
  • O código não foi executado por mim.
  • O exemplo é sintético e não representa uma pessoa, organização ou sistema de relatórios real.
  • O script pressupõe que cada linha do CSV representa uma atividade contável.
  • O script pode conciliar horas e status registrados, mas não pode verificar se as entradas originais são verdadeiras, completas ou classificadas corretamente.
